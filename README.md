# Repo for my jumpstart for haven!
This is a simple transformer game where you need to jump around to reach higher levels! Use WASD or arrow keys and spacebar to move
itch.io link for the game can be found at- [https://sugarcaen.itch.io/jumpstart-platformer-game](https://sugarcaen.itch.io/jumpstart-platformer-game)
## To run locally-
```git clone https://github.com/bamb-boo/jumpstart/```
Go to godot project manager, click import, browse to where the zip file of the repo is stored at, select project.godot and import!
Made in godot.
